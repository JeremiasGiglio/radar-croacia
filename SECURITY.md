# Seguridad

Si encontrás un problema de seguridad (por ejemplo, una forma de inyectar contenido en la web o una clave expuesta), **no abras un issue público**.
Reportalo de forma privada desde la pestaña **Security → Report a vulnerability** de este repositorio.

Medidas actuales: política de seguridad de contenido (CSP) en la web, texto externo siempre escapado, sin claves en el repo, dependencias revisadas por Dependabot.
